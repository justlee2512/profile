# Portfolio — LÊ ANH TUẤN

Node.js portfolio website with no additional package installation required.

## Run the website

```bash
ADMIN_PASSWORD='mat-khau-cua-ban' npm start
```

Open `http://localhost:3000`.

## Content management

Go to `/login`, sign in with the `ADMIN_PASSWORD` environment variable, then select **Edit site**. You can update text, skills, projects, banner image URL, or upload a banner image from your computer.

If `ADMIN_PASSWORD` is not provided, the default password is `doi-mat-khau-ngay` — use it only for local previews.
